# Project-Specific Rules

## Commenting Guidelines for AI Agents

Every time code is added, updated, or created, every line or block of lines must have detailed comments explaining what the line/block means or what it is doing.

This ensures readability, code maintainability, and clear explanations for all modifications.

### Rules:
- **Format**: For JavaScript/JSX, use standard `//` line comments or `/* ... */` block comments. For Python, use `#` comments. For HTML/XML, use `<!-- -->` comments.
- **Detail**: The comments should clarify the intent, parameters, return values, state changes, or business logic associated with the line/block of code.
- **Coverage**: Keep comments clean but thorough. Do not omit explanations for complex lines or functions.
